# Pilot 8: prediction questions

Answered before any result: Claude first (sealed, only the hash committed), then Jasper. Numbers: a
best guess and an 80% range. Probabilities: 0-100%. Scored as in pilots 5-7.

1. **The ingredients explain the worth (W1):** probability that the five ingredients, added up,
   predict the held-out outcomes' worth with R² ≥ 0.7.
2. **The biggest ingredient:** which one moves worth the most: domain (largest of the three domain
   differences), gain vs prevented loss, size, children vs adults, or poverty?
3. **Children:** how many adults one child counts as, in the model's choices (1 = the same).
   Best guess and 80% range.
4. **Assembled on the outcome's own words (W2):** probability that the worth is already put together
   on the outcome's own words, before the model reads the other option, with each ingredient
   weighted as in the choices.
