Same value, wildly different prices

Qwen3-14B priced 96 outcomes, four for each of 24 values, from 45,600 forced choices between them. The averages of the 24 values span only 5.3 price units. The four outcomes inside a single value span 6.8 at the median, and up to 10.6.
How big the outcome is explains 63% of the spread in prices; which value it serves, 20%. Each row shows a value's cheapest outcome (below the line) and its dearest (above), as in the prompt “8 people each …”. Prices: P(A) = σ(uA − uB + b·log(nA/nB) + c), fitted by maximum likelihood. Data: pilot 10.
